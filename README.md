### BlendView

Blendview est un plugin pour le logiciel de modélisation 3D Blender.
il permet la generation d'un RIG de camera pour la generation de d'image et de video autostereoscopique

### Installation
1. Téléchargez le fichier ZIP du plugin BlendView depuis le dépôt officiel ou une source fiable.
2. Ouvrez Blender et allez dans `Edit` > `Preferences`.
3. Dans la fenêtre des préférences, sélectionnez l'onglet `Add-ons`.
4. Cliquez sur le bouton `Install...` en haut à droite.
5. Sélectionnez le fichier ZIP téléchargé et cliquez sur `Install Add-on`.
6. Une fois installé, recherchez "BlendView" dans la barre de recherche des add-ons.
7. Cochez la case à côté de "BlendView" pour activer le plugin.
8. Cliquez sur `Save Preferences` pour enregistrer les modifications.

### Utilisation
1. Après avoir activé le plugin, vous trouverez un nouveau panneau dans la vue 3D sous l'onglet `N` (panneau latéral).
2. Dans ce panneau, vous pouvez configurer les paramètres du RIG de caméra, tels que le nombre de vues, la distance interoculaire, et d'autres options spécifiques à l'autostéréoscopie.
3. Cliquez sur le bouton `Generate Camera Rig` pour créer le RIG de caméra dans votre scène.
4. Vous pouvez ensuite positionner et animer le RIG de caméra comme vous le feriez avec n'importe quel autre objet dans Blender.
5. Pour rendre des images ou des vidéos autostéréoscopiques, configurez les paramètres de rendu selon vos besoins et lancez le rendu.
